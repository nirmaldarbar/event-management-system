# EventHub frontend (React + Tailwind CSS + shadcn/ui)

Poster / neo-brutalist theme: thick borders, flat bright colours, hard shadows. Light and dark mode.

```bash
npm install
cp .env.example .env
npm start
```

- Design tokens: `src/index.css` (`:root` and `.dark`) and `tailwind.config.js`
- shadcn/ui components: `src/components/ui/`
- Shared building blocks: `src/components/common/`
- `npm start/build` use CRACO (needed for the `@/` alias).
